# Contributing

Open a pull request from a branch. Do not push extra commits to `main` after the initial commit.

1. Branch from `main`.
2. Keep the change one story. Prefer a small PR.
3. Run `npm test` and `npm run typecheck`.
4. Write the PR in English using the template in `.github/PULL_REQUEST_TEMPLATE.md`.
5. Commits use Conventional Commits: `type(scope): subject`.

Read `AGENTS.md` before changing wrap, hop, or `DesiredState`.
