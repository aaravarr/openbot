# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Our standards

Be respectful. No insults, harassment, or personal attacks. Disagree with ideas, not people.

## Enforcement

Project maintainers may remove comments, commits, and PRs that violate this code. Report problems via a private GitHub security advisory or a private maintainer contact on the GitHub org.
